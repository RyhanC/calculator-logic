# Calculadora Básica

Uma calculadora simples desenvolvida em JavaScript com o objetivo de praticar lógica de programação.

## Funcionalidades

* Operações matemáticas básicas.
* Código organizado e de fácil leitura.
* Comentários explicativos para facilitar o aprendizado.
* Projeto ideal para iniciantes em JavaScript.

Este projeto foi criado como exercício de estudos e demonstra conceitos fundamentais da linguagem, servindo como base para projetos mais avançados.
